04Security is the floor, not a feature

Row-Level Security

Every session sets app.role / app.staff_id; PostgreSQL itself refuses rows the role may not see. Health data sits behind the strictest policy in the system.

Permissions matrix

perm_matrix rows (owns / sees / landing per module × role) drive each sidebar live. The matrix adds visibility — it can never exceed the RLS floor.

Audit spine

Append-only, partitioned monthly: actor, action, entity, before/after JSON. "Who did this?" is a query, not an investigation.

Approvals engine

Exeats, leave, payroll, petty cash, purchases: request → pending → decided, decider audited. Nothing bypasses; nothing auto-spends.

Multi-tenancy: one deployment, many schools — separate databases, resolved by subdomain from the control registry. Kenya DPA-minded consent & retention built in.
